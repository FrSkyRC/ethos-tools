# Ethos Tools

A collection of tools and utilities built around [FrSky Ethos](https://www.frsky-rc.com/), covering areas such as simulation, audio, translations, and more.

## Contents

- [`simulation/`](simulation/README.md) — tooling to run the Ethos WebAssembly simulator build from the command line (see [`run_wasm.js`](simulation/run_wasm.js)), useful for scripted testing, macros, and CI.
- [`manual-sync/`](manual-sync/README.md) — syncs real manual content from `ethos-manual`'s `.odt` master files into `ethos-manual-rework`'s docs (see [`sync.py`](manual-sync/sync.py)).

More tools (audio processing, translation/localization helpers, etc.) will be added here over time, each in its own subdirectory with a dedicated README.
